OVERVIEW: Describes the Target

USAGE: taptaptap describe [--udid <udid>] [--diagnostics] [--json]

OPTIONS:
  --udid <udid>           The UDID of the simulator. Defaults to the sole
                          booted simulator.
  --diagnostics           Fetch additional target diagnostics (accepted; no
                          extra diagnostics beyond this output).
  --json                  Create json structured output.
  --version               Show the version.
  -h, --help              Show help information.
