OVERVIEW: Describes Accessibility Information for the entire screen

USAGE: taptaptap ui describe-all [--udid <udid>] [--nested] [--filter <filter>]

OPTIONS:
  --udid <udid>           The UDID of the simulator. Defaults to the sole
                          booted simulator.
  --nested                Will report data in the newer nested format, rather
                          than the flat one.
  --filter <filter>       Which elements the read reports: all of them (the
                          default), or only the interactable ones — those that
                          carry a label, an identifier or an actionable role.
                          (values: all, interactable; default: all)
  --version               Show the version.
  -h, --help              Show help information.
